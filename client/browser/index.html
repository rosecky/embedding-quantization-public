Quantized query encoder in the browser (llama.cpp / WebAssembly via wllama)

Loads a GGUF query encoder, encodes the SciFact test queries one at a time and scores them against the fp32 document index in JavaScript. URL parameters: model (path relative to the repo root), threads (default navigator.hardwareConcurrency; 1 = single-thread build), ctx (512), n (300), warmup (3), tag, auto (1 = start immediately).
